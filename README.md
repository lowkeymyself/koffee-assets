# koffee-assets

Public asset host for the Koffee UI suite. Fonts are fetched at runtime by
koffee.lua and registered as custom font families; icons, effects and sounds are
cached under `Koffee/` the same way. No source code lives here.

## Fonts

Every face below is open-licensed (SIL OFL 1.1, except ProggyClean which is MIT).

| File | Face |
|---|---|
| `ProximaSoft-*.otf` | Proxima Soft (menu face) |
| `MinecraftBold.otf`, `MinecraftRegular.otf` | Minecraft |
| `ProggyClean.ttf` | ImGui |
| `BurbankBigCondensed-Black.otf` | Fortnite HUD |
| `NotoSans-Regular.ttf` | Noto Sans |
| `Inter.ttf` | Inter |
| `JetBrainsMono-Regular.ttf` | JetBrains Mono |
| `Rajdhani-Regular.ttf` | Rajdhani |
| `ChakraPetch-Regular.ttf` | Chakra Petch |
| `BebasNeue-Regular.ttf` | Bebas Neue |
| `Orbitron.ttf` | Orbitron |
| `Verdana.ttf` | Verdana |

Inter and Orbitron are variable fonts, so they render at their default weight.
